1. RLC串联电路的谐振（电压谐振）
	（1） 谐振：电感和电容的作用相互抵消了
	（2） 角频率 $\omega_ {0}$： $\frac{1}{\omega C} = \omega L \Rightarrow \omega_ {0} = \frac{1}{\sqrt{LC}},f_ {0} = \frac{1}{z\pi\sqrt{LC}}$
	（3） 品质因数： $Q ≝ \frac{\omega_ {0}L}{R} = \frac{1}{\omega_ {0}CR} = \frac{1}{R}\sqrt{\frac{L}{C}}$
	（4） 有功功率（谐振时）： $P = UI\cos\varphi = UI = U_ {R}^{2} / R = U\frac{2}{R}$
	（5） 谐振时（只是和为0，分别不一定为0）： $Q\left( j\omega_ {0} \right) = Q_ {L}\left( j\omega_ {0} \right) + Q_ {c}\left( j\omega_ {0} \right) = 0$
2. RLC串联电路的频率响应：串联谐振，相当于短路
3. RLC并联谐振电路
	（1）源的频率=电路谐振频率，则发生谐振
	（2）并联谐振，相当于开路（并联谐振外面部分电路就是0，内部不是）
