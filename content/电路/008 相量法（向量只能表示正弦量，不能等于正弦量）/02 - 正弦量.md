1.  瞬时值表达式 ${i}(t) = I_ {m}\cos(\omega t + \varphi)$
	三要素
		(1)  幅值(振幅、最大值)： $I_ {m}$
		(2)  角频率： $\omega$= $2\pi f$
		(3)  初相位： $\varphi$      （$|\varphi| \leq \pi$）
2.  同频率相位差(设 $u(t) = U_ {m}\cos\left( \omega t + \varphi_ {u} \right)$， ${i}(t) = I_ {m}\cos\left( \omega t + \varphi_ {i} \right)$ )
	 $\varphi = \varphi_ {u} - \varphi_ {i}$
	 $\varphi > 0$，u超前i $\varphi$角，或i滞后u $\varphi$角； $\varphi < 0$，i超前u $\varphi$角，或u滞后i $\varphi$角
	 特殊相位关系：同相 $\varphi = 0，$反相 $\varphi = \pm \pi$，正交 $\varphi$= $\frac{\pi}{2}$
3.  同频、同名、同号才能求相位差
4.  正弦电压有效值与最大值关系： $U_ {m} = \sqrt{2}U$
5.  常用值 工业电压380V（=220 $\sqrt{2}$ V） 频率50Hz即频率314
