## 1. 初识 C++

### 1.1 编写程序的基本步骤

1. **变量定义** —— 声明程序要用到的数据
2. **变量赋值** —— 给变量填入初值
3. **算法** —— 用表达式、语句描述处理过程
4. **结果输出** —— 通过 `cout` 等将结果呈现出来

### 1.2 程序的组成

- 一个 C++ 程序可由若干个**源程序文件**组成；
- 一个源程序文件可由若干个**函数**组成；
- 一个函数可由若干条**语句**组成；
- 语句是 C++ 程序中具有独立功能的基本单位，相当于自然语言文章中的一个句子。

## 2. 字符集与数据类型

### 2.1 字符集

C++ 的字符集由 ASCII 码中的可见字符构成。关键字、用户自定义标识符和运算符等均由 C++ 字符集中的符号组成。

- **关键字**：由 C++ 预先约定、用于固定用途的字符序列。
- **自定义标识符（变量名称）**：只能由字母、数字和下划线 3 种字符组成，且**不能以数字开头**，**不能是关键字**。
- **分隔符**：用来分隔各语法单位，常用的有空格、制表符、换行符、注释符、运算符和标点符号。

**常用标点符号及其作用：**

| 符号 | 作用 |
|------|------|
| `，` | 作数据分隔或作运算符 |
| `；` | 语句结束符 |
| `：` | 作语句标号 |
| `｛｝` | 作复合语句的标记符，或自定义类型的成员范围 |
| `'` | 作字符常量标记符 |
| `()` | 作运算符运算次序标记符，或用于函数参数及调用 |
| `"` | 作字符串常量标记符 |
| `…` | 作可变参数 |

### 2.2 数据类型

C++ 基本数据类型包括：

| 类型 | 说明 |
|------|------|
| `bool` | 布尔型 |
| `int` | 整型 |
| `float` | 单精度实型 |
| `double` | 双精度实型 |
| `char` | 字符型 |
| `void` | 空类型 |

> 注意：对每种数据类型，C++ **没有统一规定**精度、数据范围和在内存空间中所占字节数，实际大小取决于编译环境。

### 2.3 常量

#### 2.3.1 整型常量

- **十进制**（0～9）、**八进制**（0～7）、**十六进制**（0～9、A～F）。
- 八进制以 `0` 开头（如 `0678` 是**非法常量**），十六进制以 `0x` 或 `0X` 开头。
> 十六进制展开示例：

> ```
> 0X94BC = 9×16³ + 4×16² + 11×16¹ + 12×16⁰
> -0X5a = -(5×16¹ + 10×16⁰)
>  ```

- 后缀 `L`（或 `l`）：长整型数；后缀 `U`（或 `u`）：无符号型整数常量。

#### 2.3.2 实型常量

又称浮点数或实数，可用**小数**或**指数**两种形式表示。

- **小数形式**：默认为双精度；加后缀 `L`/`l` 表示长双精度实数；加后缀 `F`/`f` 表示单精度实数。
- **指数形式**：由尾数和指数组成，用 `E`/`e` 隔开。**指数部分不可省且必须为整数**；尾数的小数部分和整数部分只可省略其一。

> 常量小数点前后的 0 可以省略，例如 `0.5` 可写作 `.5`，`5.0` 可写作 `5.`。

#### 2.3.3 字符常量

- **基本表示法**：字符标志为一对单引号 `' '`，如 `'a'`、`'A'`、`'0'`（`'0'` 相当于整数 48）。
- **转义表示法**：单引号加反斜杠 `'\ '`，要表示的字符位于反斜杠后，为特定含义的字符，或字符的八进制 / 十六进制 ASCII 值。如：
  - `'\n'` 换行
  - `'\t'` 水平制表符（横向跳格）
  - `'\0'` 空字符（与 `'0'` 不同，`'0'` = 48）

> `'ab'` 这种写法一定是错误的，要么是 `'a'`，要么是 `'b'`——单引号内只能有一个字符。

#### 2.3.4 字符串常量

- 标志为一对双引号 `" "`，要表示的字符序列位于两个双引号之间。
- 字符串都隐含一个特殊字符 `'\0'`（字符串结束标记）。
- `'\0'` 是 ASCII 值为 0 的字符，等同于整数 0；`'\0'` 作为逻辑值等同于 `false`。
- `'a'` 是一个字符，而 `"a"` 是有 2 个字符组成的字符串（字符 `a` + 结束符 `'\0'`）。

### 2.4 变量

变量是可以改变值的量。一个变量有一个名字，其本质是**在内存中分配一块存储空间**，用以存储或读取数据。

#### 2.4.1 变量的使用要点

1. 变量**必须先定义后使用**。变量定义后可存放相应的数据，即为变量赋值。
2. **指针变量**中存放的是地址，可用该地址取到相应内存中的数据。
3. **引用变量**是为某个已有变量起的别名，实质与已有变量是同一个变量，故任何时候其值都与原变量的值相同。

#### 2.4.2 输入输出

使用 `cin` 从键盘读取、`cout` 输出，头文件为 `<iostream>`：

```cpp
cin >> 变量1 >> 变量2 >> ... >> 变量n;
cout << 表达式1 << 表达式2 << ... << 表达式n;
```

- `cin` 用空格、水平制表符（Tab）或回车符作为分隔，最后以回车符确认。
- 输入数据的类型应与变量的类型一致，否则变量赋值会出现异常。
- 空格和回车符本身也是字符，但用 `cin >>` 输入时不能接收它们，此时可用 `cin.get()` 实现输入。

```cpp
char ch;
cin.get(ch);   // 一次读入一个字符，包括空格和回车
```

> `cin.get()` 只能接受字符参数，不能接受 `int` 类型的参数。`cin >>` 可以接收 `char` 类型，且会自动忽略空格、制表符和换行符等分隔符，直到遇到下一个分隔符或输入结束。

  - **流程控制语句**：控制上述操作运算的执行顺序。

- 在 C++ 中使用**分号 `;` 表示一条语句结束**。

## 4. 运算符与表达式

### 4.1 基本概念

- **运算符**：对数据（常量、变量、表达式等）进行运算或处理的符号。
- **操作数**：参与运算的数据。按操作数个数分为：
  - **单目运算符**：有一个操作数；
  - **双目运算符**：有两个操作数；
  - **三目运算符**：有三个操作数。
- **优先级**：表达式有多个运算符时，按优先级从高到低运算。
- **结合性**：一个操作数左右两边运算符的优先级相同时，按结合方向运算。右结合运算符自右向左，左结合运算符自左向右。
- **表达式**：将运算符和数据按语法规则结合起来的式子。

C++ 常用运算符种类：算术运算符、关系运算符、逻辑运算符、赋值运算符等。

### 4.2 算术运算符

#### 除法 `/`

当两个操作数均为整数，且运算符右边的数不为 0 时，运算后**舍去小数部分只取整数**：

```cpp
5 / 4 == 1
```

#### 取余 `%`（求模）

当两个操作数均为整数，且运算符右边的数不为 0 时，结果为两个整数相除后的余数：

```cpp
6 % 7  == 6
-7 % 6 == -1
7 % -6 == 1
```

> 两个整数中有负数时，先用两数绝对值求余，最后结果的**符号与被除数相同**。
>
> `%` 只针对两个整型操作数，`7.5 % 3` 这类写法是错误的。

#### 自增 `++` / 自减 `--`

- **前置**：操作数先自增（自减）后，其值参与当前表达式的运算；
- **后置**：先取操作数参与当前表达式的运算，然后再使操作数自增（自减）。

### 4.3 赋值运算符

赋值运算符左边只能是**变量**，不能是常量或表达式：

```cpp
变量名 = 表达式;
```

> **举例**：赋值运算符是右结合的，结合顺序从右往左。因此：
>
> ```cpp
> a = a1 + a2 = 3 * 5;   // 错误！
> ```
>
> 这个表达式是错误的：先计算 `3 * 5` 得 15，将 15 赋值给 `a2`，而 `a1` 并没有被赋值，`a1` 的值未定义。

**复合赋值运算符**：算术运算符（在前）与赋值运算符（在后）的结合。功能是先将右操作数与左操作数进行相应的算术运算，然后再将运算结果赋值给左操作数。必须遵循赋值运算与算术运算双重规则的制约：

```cpp
int x = 5, y = 6, z = 7;
z %= 5.0;    // 语法错误：% 运算符的操作数必须为整型
x + y += z;  // 语法错误：= 运算符的左操作数必须为变量
```

### 4.4 关系运算符

`>`（大于）、`>=`（大于等于）、`<`（小于）、`<=`（小于等于）、`==`（等于）和 `!=`（不等于）。

- 关系运算比较两个操作数的大小，结果为逻辑值 `true`（真）或 `false`（假）：关系成立为 `true`，否则为 `false`。
- `true`（1）或 `false`（0）可以作为整数参与进一步的运算：

```cpp
int a = 3, b = 3, c = 3;
a == b == c;   // 将 a==b 的结果 true(1) 与 c 比较，结果为 false
```

> **区分 `=` 与 `==`**：`=` 是赋值，`==` 是相等比较，二者含义完全不同。

### 4.5 逻辑运算符

- `!`：非运算，结果取反，`true` 变 `false`，`false` 变 `true`；
- `&&`：与运算；
- `||`：或运算。

逻辑运算的操作数为逻辑值，逻辑运算的结果为逻辑值。

> **逻辑运算的优化**：逻辑运算过程中，一旦结果已确定，将终止表达式的运算（短路求值）。

> 在逻辑运算中，所有非零值都表示逻辑真（`true`），0 表示逻辑假（`false`）。
>
> 一个表达式若没有被赋给任何变量、也没有被用于其他操作，其结果可被忽略（无实际作用）。

### 4.6 sizeof 运算符

求某种数据类型或数组占内存空间的大小：

```cpp
sizeof(类型名)    // 或
sizeof(表达式)

cout << sizeof(char) << sizeof(2.0F) << sizeof(2.0);  // 输出 148（C++规定 char 占 1 字节，加F后缀的2.0F是 float 占 4 字节，不加后缀的2.0默认是 double 占 8 字节）
```

- `sizeof(aa)` 求的是数组 `aa` 占空间的大小，除以 `sizeof(aa[0])`（每个元素占空间的大小）即为数组元素个数：

```cpp
int n = sizeof(aa) / sizeof(aa[0]);
```

### 4.7 条件运算符（三目运算符）

C++ 中**唯一的三目运算符**：

```cpp
表达式1 ? 表达式2 : 表达式3
```

运算规则：先求解表达式1 的值，若为真，整个表达式的值为 表达式2 的值，表达式3 不运算；若为假，整个表达式的值为 表达式3 的值，表达式2 不运算。

### 4.8 逗号运算符

又称**顺序求值运算符**，是 C++ 中**优先级最低**的运算符：

```cpp
表达式1，表达式2，...，表达式n
```

运算规则：依次从左到右运算，并将**最后一个表达式的值**作为整个逗号表达式的值。

### 4.9 表达式中数据的类型转换

表达式中相同类型的数据才能运算，若操作数类型不同，必须转换成相同类型的数据。

**1. 自动类型转换（隐式转换）**：基本原则是将精度较低的类型向精度较高的类型转换：

```
char → short → int → long → float → double
```

- 字符参与运算时，转换成整数（ASCII 码值）。
- 赋值运算时，将右操作数转换成左边变量的类型。
- 只是将转换后的数据参与运算，**并不改变其原有类型**。

> 注意区分表达式中的常量：`2` 与 `2.0` 类型不同，参与运算得到的结果也不同（如 `2 / 3` 与 `2.0 / 3`）。  
> 2.0 / 3 = 0.666667  
> 2 / 3 = 0 (整数除以整数，结果仍然是整数，且直接丢弃小数部分，而不是四舍五入）

**2. 强制类型转换（显式转换）**：将表达式强制转换到某个指定类型：

```cpp
(数据类型名)表达式     // 或
数据类型名(表达式)

cout << 'a' + 1;   // 输出整数 98（'a'的 ASCII 码值是97）
```

### 4.10 表达式格式：C++ 与数学表达式

**1. C++ 运算符与数学运算符**

- 有些数学运算符 C++ 中用函数代替，如根号用 `sqrt`，绝对值 `|x|` 用 `fabs(x)`，需包含头文件 `<cmath>`；
- 相同书写的运算符含义不同，如 `!` 在数学中表示阶乘、在 C++ 中表示非；
- 相同运算符的书写方式不同，如数学中的 `≥` 与 C++ 中的 `>=`。

**2. C++ 表达式与数学表达式**

- C++ 只能用圆括号指定运算次序，如 `((a + b) * c + d) * e`；
- C++ 不能省略运算符，如 `(a-b)(c-d)` 应写作 `(a-b) * (c-d)`；
- C++ 通常没有数学常数，如 `π` 需要自己表示（`const` / 函数）；
- 常量的表示方式不同，如 `10⁻⁵` 写作 `1.0E-5`；
- 相同运算、操作数类型不同，结果不同，如 `2 / 3` 与 `2.0 / 3`；
- 相同运算、表达式不同，如 `a < b < c` 与 `a < b && b < c` 语义不同。

### 4.11 应用示例：逐位取出整数

利用整除与取余，可以逐位取出一个整数的各位数字：

```cpp
int x,y,m=3634;
    
x = m % 10;     //取最后一位
y = m / 10;       //去掉最后一位
------
x = 4
y = 363
```

每执行一次 `m /= 10` 就削掉一位，重复即可从个位开始逐位取出所有数字。

## 5. 程序的基本控制结构

### 5.1 顺序结构

按语句块编写顺序依次执行。

### 5.2 选择结构（分支结构）

有 `if` 语句、`if…else` 语句和 `switch` 语句。

```cpp
if (表达式) 语句块;

if (表达式) 语句块A;
else 语句块B;
```

```cpp
switch (表达式) {
    case 常量表达式1: 语句序列1; break;
    case 常量表达式2: 语句序列2; break;
    case 常量表达式n: 语句序列n; break;
    default: 语句序列n+1;
}
```

**switch 要点：**

- `switch` 和 `case` 后的表达式应为**整型**；`switch` 后通常为变量，`case` 后必须为常量，且值互不相等；
- 每条 `case` 后面的 `break` 语句保证实现多选一；
- `break` 语句和 `default` 分支不是必须的。

**执行流程：**

1. 计算 `switch` 后表达式的值；
2. 将上述值与各 `case` 后的表达式值进行匹配（比较表达式的值）；
   - 若匹配成功（找到一个值相等的分支），执行该分支；
   - 否则执行 `default` 分支；若无 `default` 分支，结束 `switch` 语句执行。
3. 执行过程中，若遇到 `break` 语句，结束 `switch` 语句；否则一直执行完最后一个分支退出 `switch` 语句。

### 5.3 循环结构

循环分为**当型循环**（`for`、`while`）和**直到型循环**（`do-while`）。

**for：**

```cpp
for (表达式1; 表达式2; 表达式3)   // 先执行1，再算2，若为真则执行循环体和3再返回2，否则跳出循环
    循环体;                       // for语句头部的第二个表达式省略时，其缺省值为1
```

**while：**

```cpp
while (条件表达式)
    循环体;
```

**do-while：**

```cpp
do {
    循环体;
} while (条件表达式);
```

- 当型循环先判断条件再执行循环体，循环体有可能**一次也不执行**；直到型循环先执行循环体再判断条件，循环体**至少执行一次**。
- `for` 括号内必须含 3 个部分，每部分用分号分隔，并且**都可以是空表达式**。
- 当循环体不止一条语句时，必须用花括号将语句组括起来。

> **循环语句的条件可以空缺**：条件空缺时缺省值为真（相当于无限循环），需要配合 `break` 等退出。

- 选择语句、循环语句均可以自己嵌套，并且可以相互嵌套；嵌套时**可以层层嵌套，但不可以交叉嵌套**。
- 当需要改变正常语句执行的次序时，可使用控制执行顺序的语句。
- `do-while` 允许从外部转到循环体内，而 `for` 和 `while` 不可以。

### 5.4 break 与 continue

- **`break`**：只能用在 `switch` 语句和循环语句中，作用是跳出 `switch` 或循环，执行其后的语句。
- **`continue`**：使程序跳过当前循环中的剩余语句，立即开始下一次循环。注意：`continue` **不是终止循环语句的执行**。

## 6. 函数

### 6.1 函数定义

```cpp
函数类型 函数名(形参列表)     // 函数头部
{
    语句序列
}                             // 函数体（括号内）
```

- 每一个形参都要有**类型、名称**，用逗号分隔。

### 6.2 函数类型与 return

按是否有返回值分为：**无值型函数**（函数类型为 `void`）和**有值型函数**。

`return` 语句：有无返回值都能用。

- 有返回值：`return 表达式;` 或 `return (表达式);`
- 无返回值：`return;`（仅起结束函数调用的作用）

> 关键字 `void` 即无值型函数类型：函数不返回任何值。

### 6.3 函数调用

```cpp
函数名(实际参数)    // 实参无类型
f(8);
```

**嵌套调用**：不允许嵌套定义（在函数体内再定义函数），但允许函数的嵌套调用（调用函数过程中再调用其他函数）。

**递归调用**：调用自身函数（**直接递归**），或两函数相互调用（**间接递归**）。有**递推、回归**两个阶段。

### 6.4 函数原型说明

**调用在前、定义在后时，就要说明函数原型：**

```cpp
函数类型 函数名(形参列表);   // 类型必须，名称可无；最后的分号不可少
void f(int);
```

### 6.5 函数的参数传递

三种方式：**值传递、地址传递、引用传递**。

| 传递方式 | 定义时 | 用时 |
|----------|--------|------|
| 值传递 | `n` | `n` |
| 地址传递 | `*p` | `&p` |
| 引用传递 | `&r` | `r` |

- **值传递是单向传递**，形参的操作不改变实参值；
- 引用传递时形参是实参的重命名。

### 6.6 内联函数

将简单函数定义为内联函数，可在编译时将函数代码直接插入调用处，以提高程序的运行效率。

```cpp
inline 函数类型 函数名（形参列表）
{
    语句序列
}
```

> 内联函数**不是**用内存空间换取执行时间的函数，它的主要目的是为了减少函数调用和返回时的额外开销。

**内联函数定义时：**

- 内联函数仅限于简单的函数，函数体内**不应包含**循环语句、`switch` 分支语句和复杂嵌套的 `if` 语句；
- 类中说明、类外定义的不是内联函数；
- 用户指定的内联函数，系统不一定处理为内联函数。

### 6.7 exit 与 abort

库函数，头文件 `<cstdlib>`，功能是终止程序的执行。

- `exit` 函数的一般格式：`exit(表达式);`
- `abort` 函数的一般格式：`abort();`

### 6.8 函数重载

**函数重载**：函数名称相同，参数个数、类型或次序不同的函数（即同一函数有不同函数实现）。

> 函数类型不同**不能**作为函数重载的依据。

调用重载函数时，根据提供的实参确定调用哪个函数。

### 6.9 变量的作用域

变量的作用域即变量的有效使用范围，分为：

- **块作用域**
- **文件作用域**
- **函数原型作用域**
- **类作用域**
- **函数作用域**

变量又分为**局部变量**（有块作用域，仅限该块使用）和**全局变量**（有文件作用域，可在整个文件使用）。

## 7. 数组

### 7.1 一维数组

在定义数组时，下标表示**数组的大小**；而数组定义之后，下标表示**元素的位置**。

```cpp
定义：   存储类型 数据类型 数据名[数组大小]    //static int arr[5]; 
初始化： 数据名[ ] = { };                   //int arr[] = {1, 2, 3}; 
使用：   数组名[元素位置]                    //cout << arr[1]; 
```

> 数组使用是针对**元素**的，通常不能直接使用整个数组。如：

错误使用：
```cpp
int a[5];
cin >> a;   // 语法错误
cout << a;  // 逻辑错误
```

正确使用：
```cpp
int a[5];
for (int i = 0; i < 5; i++) {
    cin >> a[i];  // 逐个读取整数存入 a[0] 到 a[4]
}
for (int i = 0; i < 5; i++) {
    cout << a[i] << " ";
}
```

### 7.2 二维数组

数组名是行地址，首地址是第一行的地址。

```cpp
定义：   存储类型 数据类型 数据名[行数][列数]      // static  int arr[2][3];
初始化： 数据名[ ][ ] = { { }, { }, { } };      // int arr[][3] = { {1, 2, 3}, {4, 5, 6} };（行数可以空，编译器可以数；列数不能空，必须明确告诉编译器）
使用：   数组名[行位置][列位置]                  // cout << arr[1][2];
```

### 7.3 字符数组与字符串函数

```cpp
定义：存储类型 char 数据名[数组大小]
初始化：char 数据名[ ] = "...";            // 或 char 数据名[ ] = { "..." };
        char 数据名[ ] = { '字母', ' ', ' ', ' ' };   // 或 char 数据名[ ] = { ASCII值, ... };
```

**输入：**

```cpp
cin >> 数组名;
cin.getline(数组名, 数组大小);
```

**常用字符串库函数**（头文件 `<cstring>`）：

| 函数 | 原型 | 说明 |
|------|------|------|
| 字符串拷贝 | `char *strcpy(char *, char *)` | 将第二个字符串拷贝到第一个 |
| 字符串拼接 | `char *strcat(char *, char *)` | 将第二个字符串接到第一个末尾 |
| 字符串比较 | `int strcmp(char *, char *)` | 前大返回 1，相等返回 0，前小返回 -1（比较 ASCII 值） |
| 求字符串长度 | `int strlen(char *)` | 如 `"abc\0xyz"` 的 `strlen` 为 3，大小为（字节）8 |

> 整体使用字符数组（字符串）的库函数，头文件为 `<cstring>`。

### 7.4 指针与数组

**指针变量运算：**

```cpp
int *p1, *p2 = &a[3];   // p2 指向 a[3]
p1 = a;                 // p1 指向 a[0]，a 即是 &a[0]
*p1 = 10;               // a[0] 的值赋成 10
```

- 指针未明确所指对象之前，不能赋值（0 除外）；
- 指针操作数组时，指针类型必须与数组类型一致。

**字符数组与指针：**

```cpp
char *s1 = "C++ Program", *s2;
s2 = "This is a string.";          // 字符型指针变量指向字符串

char str[50], *s3 = str;           // 直接引用字符型指针变量所指的字符数组
```

**指针数组：**

```cpp
存储类型 数据类型* 数组名[数组大小];
```

### 7.5 数组作为函数参数


#### 一维数组：
```cpp
// 原型说明  
函数类型 函数名(数据类型* 指针名, int 变量名);    // void printArr(int* p, int size);  
// 或  
函数类型 函数名(数据类型 指针名[], int 变量名);   // void printArr(int p[], int size);

// 调用  
函数名(数组名, 数组大小);                       // printArr(arr, 5);
```

#### 字符数组：
```cpp
// 原型说明  
函数类型 函数名(char* 指针名);                  // void printStr(char* p);  
// 或  
函数类型 函数名(char 数组名[]);                 // void printStr(char str[]);

// 调用  
函数名(数组名);                                // printStr(str);
```

#### 二维数组：
```cpp
// 原型说明  
函数类型 函数名(数据类型 指针变量名(*)[N], int 变量名);         // void printArr(int (*p)[3], int row);  
// 或  
函数类型 函数名(数据类型 指针变量名[][N], int 变量名);          // void printArr(int p[][3], int row);

// 调用  
函数名(数组名, 行数);                                        // printArr(arr, 2);
```
> 二维数组的数组名代表**行指针**。对行地址进行取值可以得到元素地址，对元素地址进行取值可以得到元素。

### 7.6 动态内存分配：new 与 delete

**new 运算符**：开辟动态内存空间，本身没有名称，但可通过指向该内存空间的指针操作。

- 分配不成功时，指针变量值为 0，成功则为空间首地址；
- 指针与空间类型一致；
- 为数组或结构体分配动态内存时，不可赋初值。

```cpp
指针变量 = new 数据类型;
指针变量 = new 数据类型(初值);
指针变量 = new 数据类型[数组大小];     // 如 char *p = new char[10];
```

**delete 运算符**：释放 new 分配的动态空间。

```cpp
delete 指针变量;              // 释放单个变量空间
delete [ ] 指针变量;          // 释放所有数组空间
delete [数组大小] 指针变量;   // 释放确定大小的数组空间
```

## 8. 类与对象

### 8.1 类定义

类是 C++ 封装的核心，类有**封装性、继承性、多态性**。

```cpp
class 类名        // class 是关键字，类名是自定义标识符
{
    public:       公有成员列表;
    protected:    保护成员列表;   // 在有继承和派生相关的类中才使用，否则即使定义为保护也会说明为私有
    private:      私有成员列表;   // 没有说明则默认私有
};                 // 类体为花括号中的内容，三个部分顺序不固定
```

- 除用关键字 `static` 将成员说明为静态类型（意义是该成员为类的所有对象共有），其他关键字（`auto`、`register`、`extern`）不行；
- 除类的静态成员外，**不能在类的定义过程中给成员赋初值**；
- 类的成员函数可直接使用自身成员，不受限制；
- 类外定义时应用作用域运算符 `::` 表明该函数是类的成员（类体内直接定义的一般较短小）：

```cpp
函数类型 类名::函数名...
```

- 私有成员类外通过公有成员间接访问：

```cpp
int geta() { return a; }
```

### 8.2 构造函数、析构函数、拷贝构造函数

- **构造函数**：用于初始化对象，与类同名，无函数类型，无 `return` 语句。
- **默认构造函数**：无参数，无语句，仅生成对象而不初始化对象（没有定义构造、析构、拷贝函数时，系统自动生成）。
- **析构函数**：无参数，无返回值。默认析构函数：`~类名() { }`（无分号）。
- **拷贝构造函数**：用已存在的对象初始化新建立的同类对象：

```cpp
类名(类名 &对象名) { /* 对象成员变量的拷贝 */ }
```

- 每个类至少有 2 个构造函数：一个是拷贝构造，另一个是普通构造；
- 拷贝构造函数必须指明成员所属对象，因为它是通过已存在对象的引用来初始化新对象。

**对象定义的几种方式：**

```cpp
A a1;          // 定义对象
A a2(4);       // 调用非默认构造函数
A a();         // 只是个函数声明（不是对象！）
A a;           // 调用默认构造函数只是为了生成对象
A *a3;         // 只是声明了指针；可用 new 操作符，实际上调用了该对象的构造函数来初始化对象
A &a4 = a1;    // 只是定义了引用，绑定到 a1
A a5[7];       // 用 7 次构造函数
```

### 8.3 对象

**定义**：以类为模板声明对象（声明对象时提供的参数应与构造函数匹配）。

- 可以定义类的同时定义对象，或定义类时不定义类名直接定义对象；
- 访问成员函数应提供实参，无参不能省略括号 `()`。

**变量与对象的三种声明对照：**

```cpp
int n;            int *p = &n;      int &r = n;
A   a;            A   *p = &a;      A   &r = a;
```

对象同样可被声明为普通对象、指向对象的指针、对象的引用，用法与基本类型变量一致。

**成员访问方式：**

```cpp
// 通过对象名和成员运算符 . 使用类的成员（类体外访问类的成员要指明它属于哪个对象）
A a;
a.print();

// 通过指针和成员运算符 -> 引用成员（两种形式）
A *p;
p = new A;
p->print();     // 形式1：通过指针引用成员
(*p).print();   // 形式2：通过指针引用成员
delete p;       // 释放动态空间
```

> `*p.print` 等同于 `*(p.print)`：对象成员运算符 `.` 的优先级高于指针取值运算符 `*`，而 `p` 是指针变量，不是对象，没有成员 `print`，所以必须写 `(*p).print()` 或 `p->print()`。

- 同一类的对象可相互赋值，常量不可被赋值。

### 8.4 成员初始化列表

成员是引用、常量、对象时，**不能在构造函数体中用赋值语句直接赋值**，应以成员初始化列表的形式提供：

```cpp
class N {
    int a, b;
    int &d;
    const int c;
    M m1;                       // M 是另一个类
public:
    N(int t): d(b), c(++t), m1(t++), a(++t) { b = 2 * t; }
};
```

- 初始化顺序由**类定义它们时的顺序**决定，先执行列表中的，再执行函数体中的。

### 8.5 this 指针

`this` 指针指向当前对象，**只有非静态成员函数中有**（类的成员函数中的成员默认有 this 指针）。

```cpp
class Q {
    int a;
public:
    Q add(int a, Q &t) {       // this 指向 q2
        this->a = this->a + a + t.a;   // q2.a = q2.a + a + q1.a
        return *this;                  // *this = q2（this 指向 q2）
    }
};

int main() {
    Q q1(1, 2), q2(0, 0);
    q1 = q2.add(5, q1);
}
```

### 8.6 静态成员

静态成员为**共享不同对象的数据**设立（不同对象的成员无关），它**属于类**（定义类时就给了静态成员空间），**不属于某个对象**。

- 用关键字 `static` 说明，分为静态数据成员、静态成员函数；
- 类中说明，类外定义（类外定义时不可使用 `static`）；
- 必须在类体外初始化，不能在构造函数中对其赋值（不然每次类有新对象都要被重置）；
- 静态成员访问可以用类或对象（非静态成员只能用对象）。

```cpp
class A {
    static int b, c;
};
int A::b, A::c = 5;   // 类外定义并初始化
```

- **静态成员函数**：无 `this` 指针，因而只能直接访问静态成员，不能直接访问类的非静态成员（可以间接访问）。

### 8.7 常成员

类的常成员包括**常数据成员**、**常成员函数**。

**常数据成员**（值为常量的数据成员）：

```cpp
const 数据类型 数据成员名;
数据类型 const 数据成员名;
```

- 初始化：只能在构造函数头部初始化列表初始化（即 `构造函数(形参): 常成员(数值)`，不要用等号）；
- 使用：只能读不能写。

**常成员函数**（只能用来读数据成员、不能用来写数据成员的成员函数）：

```cpp
函数类型 成员函数名(形参列表) const;   // const 应置于形参列表的后面，不能置于前面
```

- 常成员函数与非常成员函数构成重载关系。

**常对象**（数据成员的值不能改变的对象）：

```cpp
类名 const 对象名(实参列表);
const 类名 对象名(实参列表);
```

- 常对象的数据成员不一定是常成员——关键在于，一旦被声明为常对象，它**所有成员的值都不能改**。

**使用规则：**

- 非常对象可调用常成员函数、非常成员函数；
- 常对象只能调用常成员函数，不能调用非常成员函数；
- 重载时，常对象调用常成员函数，非常对象调用非常成员函数（各调各的）；
- 常成员函数既能访问常成员数据，也能访问非常成员数据。

```cpp
class Myclass {
    int m;
    const int n;
public:
    Myclass(int x, int y): n(y) { m = x; }
    void print() const { cout << m; }   // A行：常成员函数
    void print() { cout << n; }         // B行：非常成员函数（重载）
};

int main() {
    Myclass obj1(1, 2);
    const Myclass obj2(3, 4);
    obj1.print();   // C行：输出 2（非常对象调用非常成员函数）
    obj2.print();   // 输出 3（常对象调用常成员函数）
}
// 输出 23（各调各的）
```

## 9. 继承与派生

### 9.1 面向对象程序设计的基本特性

- **封装性**：通过类定义封装数据及其操作，隐藏属性；
- **继承性**：通过扩展代码模块，实现代码复用；
- **多态性**：通过虚函数提供公共接口，实现接口复用。

继承方式：单继承、多基类继承、多级继承。

### 9.2 派生类

**派生**（在已有类的基础上产生新类，即让一个类获得其他类属性的方法）。

**定义：**

```cpp
class 派生类名: 派生方式 基类名 {
    新增成员列表
};
```

- 派生方式的关键字与成员访问权限相同：`public` 公有派生；`private` 私有派生（默认）；`protected` 保护派生；
- 新增成员的定义方法与基类中成员的定义方法相同。

**派生类中的成员：**

- **新增成员**：派生类自己定义的成员；
- **派生成员**：从基类继承来的成员，即基类中的所有数据成员（虚基类除外）以及除构造函数和析构函数以外的其他成员函数。

### 9.3 派生成员的访问权限

派生成员的访问权限由**原有属性**和**派生方式**共同决定。

- **公有派生**：访问权限不变；
- **私有派生**：全变为私有成员；
- **保护派生**：除私有成员外，其他全变为保护成员。

派生类内部访问派生成员：看**原有属性**（保护成员可以直接访问）；派生类外部访问派生成员：看**派生后属性**，只有派生后仍为公有的可直接访问。

| 派生方式 | 基类原有成员 | 派生成员权限 | 内部访问方式 | 外部访问方式 |
|----------|--------------|--------------|--------------|--------------|
| 公有派生 | 公有成员 | 公有成员 | 直接访问 | 直接访问 |
| 公有派生 | 保护成员 | 保护成员 | 直接访问 | 间接访问 |
| 公有派生 | 私有成员 | 私有成员 | 间接访问 | 间接访问 |
| 私有派生 | 公有成员 | 私有成员 | 直接访问 | 间接访问 |
| 私有派生 | 保护成员 | 私有成员 | 直接访问 | 间接访问 |
| 私有派生 | 私有成员 | 私有成员 | 间接访问 | 间接访问 |
| 保护派生 | 公有成员 | 保护成员 | 直接访问 | 间接访问 |
| 保护派生 | 保护成员 | 保护成员 | 直接访问 | 间接访问 |
| 保护派生 | 私有成员 | 私有成员 | 间接访问 | 间接访问 |

### 9.4 多继承

多继承包括**多基类继承**、**多级继承**。

**多基类继承**（派生类具有两个或两个以上基类的继承方式）：

- 是单继承的简单扩展，派生类与每个基类间仍是单继承；
- 派生类包含各个基类的成员，以及新增成员；
- 派生成员访问权限由各自的原有属性和派生方式决定。

```cpp
class 派生类名: 派生方式1 基类名1, 派生方式2 基类名2, ..., 派生方式n 基类名n {
    新增成员列表
};
```

**多级继承**（以一个派生类为基类，产生另一个新的派生类的继承方式）：

```
A ← B ← C
```

类 B 是类 A 的派生类、类 C 的基类；类 C 的基类 B 是类 A 的派生类，所以类 C 是一个多级继承。

### 9.5 赋值兼容性

**赋值兼容性**：公有派生时，可将派生类的数据赋值给基类数据的关系，**单向**！（通常只有同类型的对象才能赋值）。

三种形式：

1. 将派生类对象赋值给基类的对象；
2. 用派生类对象初始化基类对象的引用；
3. 将派生类对象地址赋值给基类指针，即基类指针指向派生类对象。

```cpp
class Base { public: int b; void show() { cout << b << '\n'; } };
class Derived: public Base { public: int d; void show() { cout << b << '\t' << d << '\n'; } };

int main() {
    Base t1 = {1}, *p;
    Derived t2;
    t2.b = 5, t2.d = 10;

    t1 = t2;       // 对象之间的赋值
    t1.show();     // t1：b、show

    Base &t3 = t2; // 初始化引用：p 是基类指针，只能访问派生成员
    t3.show();     // t3 → t2

    p = &t2;       // 指针指向对象
    p->show();
    return 0;
}
```

> **基类指针指向派生类对象时，通常只能访问派生成员，而不能访问新增成员，除非该新增成员是虚函数！**

### 9.6 派生类的构造函数与析构函数

- 在构造函数头部通过调用基类构造函数初始化派生成员；
- 在函数体中初始化新增成员。

**单继承时派生类的构造函数：**

```cpp
派生类名(形参列表): 基类名(实参列表) {   // 派生类名：构造函数名；基类名：基类构造函数名
    新增成员初始化列表                    // 形参包含参数类型和名称；实参没有类型
}
```

也可类内说明、类外定义：

```cpp
派生类名(形参列表);                     // 类中说明

派生类名::派生类名(形参列表): 基类名(实参列表) {   // 类外定义
    新增成员初始化
}
```

**要点：**

- 基类构造函数的调用只能在定义时列出；
- 派生类的构造函数通常必须包括基类构造函数的调用；
- 基类有默认构造函数，则派生类构造函数头部可省基类构造函数调用（并不是不调用，而是调用基类默认构造函数）；
- 若基类没有默认的构造函数和参数，则编译报错。

```cpp
class Base {
    int b1, b2;
public:
    Base(int x, int y) { b1 = x; b2 = y; }       // 即 b1=a, b2=b
    void show() { cout << "b1=" << b1 << ",b2=" << b2 << '\n'; }
};

class Derived: public Base {
    int d1, d2;
public:
    Derived(int a, int b, int c, int d): Base(a, b) { d1 = c; d2 = d; }
    // Base 的构造函数初始化 b1、b2，再初始化 d1、d2
    void print() {
        cout << "派生成员: "; show();
        cout << "新增成员: " << "d1=" << d1 << ",d2=" << d2 << '\n';
    }
};
```

**默认构造函数与派生：**

```cpp
class A { public: A(int x = 0) { cout << x << '\n'; } };   // 有默认参数，可作默认构造
class B { public: B(int x) { cout << x << '\n'; } };        // 无默认构造
class C: public A { public: C(int x) { cout << x << '\n'; } };
class D: public B { public: D(int x) {} };                  // 语法错误：基类 B 无默认构造函数
```

**多基类派生类构造函数：**

```cpp
派生类名(形参列表): 基类名1(实参列表1), 基类名2(实参列表2), ..., 基类名n(实参列表n) {
    新增成员初始化
}
// 类外定义：
派生类名::派生类名(形参列表): 基类名1(实参列表1), 基类名2(实参列表2), ..., 基类名n(实参列表n) {
    新增成员初始化
}
```

**多级派生类构造函数：**

- 若每级的派生类都只有一个基类，则各级派生类构造函数的定义都与单继承时相同；
- 若其中某级有多个基类，则该级派生类构造函数的定义采用多基类派生类构造函数定义的方法。

**派生类对象构造顺序：**

- 先初始化派生成员，再新增成员；
- 若派生类是多级派生类，则要向上逐级调用基类的构造函数；
- 若派生类是多基类派生类，则要按照**继承顺序**逐一调用各基类的构造函数（与派生类型无关；只看类定义时继承顺序，不用管函数构造时，即基类列表与调用顺序和输出结果无关）。

**派生类析构函数**：先释放新增成员，再派生成员。

### 9.7 冲突与支配规则

**冲突**：派生类中同时存在来自不同类的名称相同的成员（来自不同基类的名称相同的派生成员；从基类继承的派生成员与派生类中的新增成员）。

- 冲突解决方法：用 `类名::` 来区分不同作用域（类）的同名成员。

**支配规则**：若新增成员与派生成员同名，没有用 `类名::` 限定时，默认新增成员。

没有出现同名冲突时，既可以用类名和作用域运算符使用成员，也可以直接使用成员，习惯于直接使用成员。

### 9.8 虚基类

同一个基类经过多级继承后会出现用 `类名::` 无法解决的冲突。

**概念**：若将共同基类设置为虚基类，则从不同的路径继承过来的虚基类的派生成员在派生类中只出现一次。

**说明虚基类的方法**：定义派生类时，在基类名称的前面加上关键字 `virtual`。

```cpp
class 派生类名: virtual 派生方式 基类名 {
    新增成员列表
};
// 或
class 派生类名: 派生方式 virtual 基类名 {
    新增成员列表
};
```

**虚拟继承的构造函数：**

- 从虚基类直接或间接继承的派生类构造函数头部，都必须列出虚基类构造函数调用，除非虚基类有默认的构造函数；
- 基类继承顺序决定基类构造函数的调用顺序！基类列表只决定派生成员的值，与调用顺序无关；
- 虚基类被剥离，其他类不用管其构造函数和成员。

**构造函数调用顺序：**

1. 首先调用虚基类的构造函数；
2. 然后按继承顺序调用基类的构造函数（不再调用虚基类的构造函数）；
3. 最后执行自身函数体。

## 10. 多态性与虚函数

### 10.1 多态性的基本概念

**多态**：不同对象收到相同指令时，产生不同的行为（一个类实例的相同函数在不同情形下有不同的表现形式）。

- **调用函数**：执行与函数名相应的某段存储空间的代码；
- **地址绑定**：函数名与存储空间首地址的匹配过程。

**1. 编译（静态）多态性**：编译时进行地址绑定。编译时根据函数参数确定调用地址，如函数重载等。

**2. 运行（动态）多态性**：运行时根据具体对象绑定地址。

- 当基类指针指向派生类对象的普通函数时，在编译时被绑定到从基类继承来的派生成员上；
- 要想绑定到派生类的新增成员上实现运行的多态性，必须把函数定义为虚函数；
- 虚函数允许在派生类中被重写（重新定义函数体），也称为函数覆盖；
- 虚函数在编译时不绑定调用地址，而是在程序运行时，根据具体的对象绑定所调用函数的入口地址。

### 10.2 虚函数实现动态多态性

**虚函数**：类中被声明为 `virtual` 的非静态成员函数。

```cpp
// 定义
virtual 函数类型 函数名(形参列表) {
    函数体
}

// 类中说明
virtual 函数类型 函数名称(形参列表);

// 类外定义
函数类型 类名::函数名(形参列表) {
    函数体
}
```

**要点：**

- 类外定义虚函数时不能用 `virtual` 说明；
- 虚函数有**遗传性**：派生类中与基类虚函数有相同函数类型、名称和参数的新增函数，不用 `virtual` 说明，仍是虚函数；
- 虚函数具有**不确定性**：不能将构造函数定义为虚函数，可以将析构函数定义为虚函数；
- 虚函数是实现动态多态性的基础和必要条件，但仅有虚函数还不能实现动态多态性。

**实现动态多态性必须同时满足下列条件：**

1. 要有具有继承关系的类，并将要实现动态多态性的函数定义为虚函数；
2. 在派生类中必须重写虚函数，即重新定义虚函数的函数体，且与基类对应的虚函数同类型、名称和参数；
3. 必须通过基类的指针或基类对象的引用调用虚函数：

```cpp
基类指针变量名->虚函数名(实参表)
// 或
基类对象引用名.虚函数名(实参表)
```

**示例：**

```cpp
class Base {
public:
    virtual void f() { cout << "Base ::f \n"; }    // 定义虚函数
};

class Derived: public Base {
public:
    void f() { cout << "Derived ::f \n"; }         // 重写虚函数
};
```

### 10.3 纯虚函数与抽象类

**1. 纯虚函数**（只声明、未定义的虚函数，无函数体）：

```cpp
virtual 函数类型 函数名(形参列表) = 0;
// 或
函数类型 virtual 函数名(形参列表) = 0;
```

**2. 抽象类**（含纯虚函数的类）：

- 抽象类只能作为派生类的基类，不能创建对象（含纯虚函数的类是一个不完整的类）；
- 可以定义抽象类的指针和对象引用，并指向或引用派生类的对象。

**3. 纯虚函数实现动态多态性**：只要在派生类中重写基类纯虚函数的函数体，便可用派生类实现动态多态性。

> 在派生类中定义基类纯虚函数的实现后（即必须在派生类中定义纯虚函数的函数体），方可产生派生类的对象。

## 11. 友元

友元是在类外部直接访问类所有访问权限成员的方案，包括**友元函数**和**友元类**（但并不是随处可见，而是需要在类中声明或定义）。

### 11.1 友元函数

友元函数是类的外部函数，即**不是类的成员函数**，无 `this` 指针，函数体中需使用对象或指针使用类的成员。需在类体中用关键字 `friend` 说明（函数类型前）。

```cpp
// 定义
friend 函数类型 函数名(形参列表) {
    函数体   // 可直接访问类中所有权限的成员
}

// 类中说明
friend 类型 函数名(形参列表);

// 类外定义
函数类型 函数名(形参列表) {
    函数体
}
```

**注意事项：**

- 类的访问控制权限对友元函数不起作用，类中任何位置声明友元函数，其作用是相同的；
- 友元函数不能直接使用类的成员，必须指明成员所属的对象，其形参通常是类的对象、对象引用或指针；
- 友元函数必须直接调用，不能通过对象调用；
- 友元函数能够提高程序的运行效率，但破坏了类的封装性；
- 友元关系**无继承性**：如 `f` 函数是基类 A 的友元函数，类 C 是类 A 的派生类，`f` 函数不一定是类 C 的友元函数。

### 11.2 友元类

所有成员函数都是另一个类的友元函数的类。类 B 是类 C 的友元类，则类 B 所有成员函数均为类 C 的友元函数。

```cpp
class C {
    ...
    friend class B;    // 将类 B 说明为类 C 的友元类
};
```

> 友元关系**无遗传性**，也**不可逆**（类 B 是类 C 的友元类，类 C 不一定是类 B 的友元类）。

## 12. 运算符重载

### 12.1 基本概念

C++ 运算符限于基本类型数据的运算，要使其能参与对象等导出型数据的运算，必须重新定义它的操作规则。方法：**定义运算符重载函数**，在函数体内通过基本类型数据（类的数据成员）的运算实现对象的运算。

- 函数名由运算符重载的**关键字 `operator`** 和**运算符**组成；
- 重载函数通常为类的成员函数或友元函数。

```cpp
// 运算符重载函数定义为类的成员函数
函数类型 operator 运算符(形参列表);

// 运算符重载函数定义为类的友元函数
friend 函数类型 operator 运算符(形参列表);
```

必须先说明类和运算符重载函数，如：

```cpp
class D;
D operator-(D, D);
```

### 12.2 重载规则

- **不能重载**：成员运算符 `.`、指针运算符 `*`、作用域运算符 `::`、条件运算符 `?:`、求字节长度运算符 `sizeof()`；
- **只能成员函数重载**：赋值运算符 `=`、数组下标运算符 `[]`、函数调用运算符 `()`、指针成员运算符 `->`；
- **只能友元函数重载**：插入运算符 `<<` 和提取运算符 `>>`。

> 记忆口诀：（只能成员函数重载）**针成调赋下**；（只能友元函数重载）**插入、提取**。

- 运算符重载**不能改变**运算符的优先级、操作数的个数和结合性等基本性质；
- 重载运算符限制在 C++ 中已有的运算符范围内，**不能创建新的运算符**。

### 12.3 成员函数重载单目运算符

```cpp
E E::operator++() {   // 前置
    ++m; ++n;
    return *this;     // *this 即 a1（this 指针指向 a1）
}
...
a1.operator++();
```

- 通常没有参数，要操作的对象通过 `this` 指针传递给运算符重载函数，即为当前对象；
- 增加一个整型参数区分 `++` 和 `--` 运算符前置与后置：

```cpp
前置++：函数类型 operator++(void);
后置++：函数类型 operator++(int);
前置--：函数类型 operator--(void);
后置--：函数类型 operator--(int);
```

### 12.4 友元函数重载单目运算符

- 通常有一个该类类型的参数（通过 `this` 指针传递操作数），用来传递要操作的对象；若通过参数带回操作结果，参数应为引用；
- 增加一个整型参数区分 `++` 和 `--` 运算符前置与后置：

```cpp
前置++：friend 函数类型 operator++(引用对象);
后置++：friend 函数类型 operator++(引用对象, int);
前置--：friend 函数类型 operator--(引用对象);
后置--：friend 函数类型 operator--(引用对象, int);
```

### 12.5 流插入与流提取运算符重载

```cpp
class K;   // 类说明
ostream& operator<<(ostream&, K&);   // 重载函数说明
istream& operator>>(istream&, K&);   // 重载函数说明

class K {
    int a[5];
    friend ostream& operator<<(ostream& out, K& t) {
        for (int i = 0; i < 5; i++) out << t.a[i] << '\t';
        return out;
    }
    friend istream& operator>>(istream& in, K& t) {
        for (int i = 0; i < 5; i++) in >> t.a[i];
        return in;
    }
};
```

### 12.6 强制类型转换运算符重载

通过重载强制类型转换运算符，可以将该类型的对象转换成其他类型的数据，也称为**转换函数**：

```cpp
operator 数据类型();
```

**定义时注意：**

- 转换函数只能为成员函数；
- 转换函数是没有函数类型的**有值型函数**；
- 函数名称由关键字 `operator` 和要转换成的数据类型组成，该数据类型即函数返回值的类型；
- 转换函数没有参数，不能被重载。

### 12.7 成员函数重载双目运算符

双目运算符有两个操作数，**左操作数为当前对象**，右操作数为重载函数的参数。

- 重载函数有一个参数，通常是对象或对象引用，也可以是整型、实型等其他类型数据；
- 若有函数重载原型：`函数类型 operator@(类类型 对象引用);`（`@` 为运算符），则对象表达式 `a1@a2` 等同于 `a1.operator@(a2)`。

### 12.8 友元函数重载双目运算符

友元函数没有 `this` 指针（当前对象），两个操作数皆为重载函数的参数，其中**至少有一个参数是对象或对象引用**。

- 若有函数重载原型：`函数类型 operator@(A &t1, A &t2);`（A 为类），则对象表达式 `a1@a2` 等同于 `operator@(a1, a2)`。
